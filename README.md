# mac-us-international-ohne-tottasten
Ein macOS-Tastaturlayout für ANSI-Tastaturen, das sich wie das Windows-Layout „US-International“ verhält, aber ohne Tottasten. Die Option-Taste (links und rechts) übernimmt die Rolle von AltGr.  Gedacht für alle, die von Windows auf den Mac wechseln und deutsche Umlaute weiter wie gewohnt tippen möchten.
